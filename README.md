# Proyecto-AEA-Seguidor-Solar
Este proyecto consiste en la realización de un seguidor solar usando de base servomotores para lograr el movimiento del panel

Creado por:
- Sebastián Pérez
- Ramiro Trejo
-  Rodríguez Thiago

Componentes:
-  AMS1117 5V
-  ATtiny 85
-  2 Sensor LDR

Para su diseño de PCB y 3D se utilizara software como KiCad y AutoDesk Fusion y Proteus para su simulacion
